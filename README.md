# Campusly

# Project Overview and Purpose
Campusly is a student organization web app prototype. It helps a student track courses, manage a to-do list, and calculate GPA all in one spot. The purpose of the project is to create a simple academic dashboard using HTML, CSS, Python, and Flask.

# Installation and Setup Instructions
1. Download or clone the project folder.
2. Open a terminal in the project root folder.
3. Install Flask
In the terminal run:
pip install flask
4. Then, from the project root folder run this in the terminal:
cd code
python app.py

Then open this link in a browser: http://127.0.0.1:5000

# How to Reproduce Results
1. Open the web app.
2. Go to the GPA Calculator page.
3. Go to Courses page.
4. Go to to-do page.
